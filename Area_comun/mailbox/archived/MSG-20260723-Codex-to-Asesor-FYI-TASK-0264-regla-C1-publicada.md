# FYI - DECISION-0103 C1 written rule published

TASK-0264 publishes the written C1 lifecycle rule in `TASK_PROTOCOL.md` and mirrors it in
`AGENTS.template.md`. A governed unit set cannot start until the human has seen and approved the
complete plan table, the approval is recorded in the signed event log or signed mailbox, and any
material unit, acceptance, or risk change is re-approved.

This publication is the written rule, not the TASK-0260 mechanical turn-zero enforcement. Each
participant remains responsible for updating only their own private startup prompt or memory.
