## Declared residuals

- R-1 (non-blocking, test portability - NOT a gate hole): the runner asserts
  `"Area_comun\state\CLAIMS.json" in output` (Windows backslash separators). The validator
  renders `{path}` via `str(Path)`, which is OS-dependent (forward slashes on POSIX). On a
  POSIX-adopting instance this negative-test assertion would FALSE-FAIL even though the gate
  fires identically. The GATE and its diagnostics are portable; only the test's substring is
  Windows-specific. Suggested follow-up: assert on separator-agnostic tokens (e.g. `"CLAIMS.json"`,
  `"Invalid JSON"`, `"collaboration state in staged snapshot is invalid"`). This does not affect
  the guarantee under review and does not gate closure on this Windows-anchored harness.
- R-2 (context, NOT a defect): partial-mode-by-default local hooks are the deliberate E6-A cost
  split owned by `.githooks/pre-commit` (TASK-0257), correctly NOT touched here and now honestly
  declared in the handoff.
- Benign validator WARNING: one FYI (requires_response:false) triggers "consider archiving";
  correct for an FYI, the Arquitecto's to archive; not a defect.
