# SPEC-0049 - D2.3: documentacion de adopcion + docs N-agente (criterio 16)

## 1. Problema

Para que la metodologia sea distribuible, un humano externo debe poder entender COMO adoptarla y operarla.
Hoy faltan: (a) guia de adopcion por tiers + upgrade + operacion de agentes reales; (b) la documentacion
N-agente del criterio 16 de SPEC-0038 (registry/routing/estados/guardrails/seguridad/handoffs). Codex ya
toco minimamente README_INSTANCIACION.md y runtime/README.md en el wrapper (TASK-0062); D2.3 AMPLIA sin
duplicar.

## 2. Alcance (TASK-0063)

1. **`README_INSTANCIACION.md`** (ampliar): 
   - Los dos TIERS DE ADOPCION (DECISION-0019): `coordination` (ligero, default) vs `runtime` (completo);
     como elegir; como instanciar cada uno (`new_instance.py --tier ...`).
   - UPGRADE: `upgrade_instance.py` tier-aware (deltas de runtime solo para tier runtime; runtime_version).
   - OPERAR AGENTES REALES via el wrapper (DECISION-0021): pasos de activacion opt-in/gateada (runtime.
     enabled + real_invoker registro + flags --allow-real-invoker/--llm-command|--llm-preset/--once),
     limites (budget/tool-policy/guardrails), sin secretos. Dejar claro que es off-by-default y que la
     autonomia NO esta incluida.
2. **Docs N-agente (criterio 16 SPEC-0038)**: un documento publicable (p.ej. `Area_comun/protocol/
   N_AGENT_RUNTIME.md` o seccion equivalente) que cubra: registry de agentes/capacidades, routing
   (weighted-least-loaded + fairness), maquina de estados Review/QA, guardrails (anti-inyeccion/tool-policy/
   firma del envelope), seguridad (identidad/limites), handoffs autocontenidos, observabilidad y budget.
3. **Coherencia**: no duplicar lo que ya esta en runtime/README.md; enlazar. Neutralidad de dominio.

## 3. Criterios de cierre

- README_INSTANCIACION cubre tiers + upgrade + operacion de agentes reales (claro, neutral, sin secretos).
- Docs N-agente (criterio 16) presentes y coherentes con el codigo (registry/routing/estados/guardrails/
  seguridad/handoffs/observabilidad/budget).
- Sin duplicacion con runtime/README; enlaces validos.
- validador/encoding/neutralidad py verdes; ASCII donde aplique a state/mailbox (docs en prosa = UTF-8 sin
  mojibake).
- Handoff autocontenido; release atomico (DECISION-0018).

## 4. Fuera de alcance

- D2.4 (SemVer del paquete + migracion). DECISION-0020. Fase B/7. Cambio de codigo del runtime (esto es
  documentacion). Cambio incompatible => blocked + pregunta.
