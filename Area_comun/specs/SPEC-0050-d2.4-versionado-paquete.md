# SPEC-0050 - D2.4: SemVer del paquete-metodologia + notas de migracion

## 1. Problema

Para distribuir, un adoptante necesita reglas claras de versionado y migracion: que significan los distintos
`*_version` (protocol_version, runtime_version, schema_version del turno, profile_version), que es MAJOR/
MINOR/PATCH para un adoptante, como se relacionan los tiers (coordination/runtime) con la compatibilidad, y
como migrar (lite->runtime, bumps de version, politica de cambios incompatibles). Hoy esto esta disperso
(DECISION-0001 versionado del protocolo; SCHEMA_VERSIONING.md del turn_schema; runtime_version en D2.2).

## 2. Alcance (TASK-0064)

1. **Documento de versionado del paquete** (p.ej. `Area_comun/protocol/PACKAGE_VERSIONING.md` o seccion en
   README_INSTANCIACION): consolida y explica para el adoptante:
   - `protocol_version` (contrato de coordinacion, DECISION-0001), `runtime_version` (motor, D2.2),
     `schema_version` del turn_schema (SCHEMA_VERSIONING.md), `profile_version` (perfiles, DECISION-0003).
   - Que es MAJOR/MINOR/PATCH desde la perspectiva del adoptante (que rompe, que es aditivo).
   - Compatibilidad por tier (coordination vs runtime) y como influye runtime_version.
2. **Notas de migracion para adoptantes**: como subir de tier (coordination -> runtime via new_instance/
   upgrade), como adoptar deltas (upgrade_instance, inform-only), politica de cambios incompatibles
   (requieren decision + aprobacion del adoptante), y referencia al CHANGELOG.
3. Enlazar (no duplicar) con DECISION-0001, SCHEMA_VERSIONING.md, README_INSTANCIACION, N_AGENT_RUNTIME.

## 3. Criterios de cierre

- Documento de versionado del paquete + notas de migracion presentes, coherentes y enlazados (sin duplicar).
- Explica los 4 ejes de version y su SemVer para el adoptante; compatibilidad por tier; migracion lite->runtime.
- Neutralidad limpia; sin secretos; validador/encoding/neutralidad py verdes.
- Handoff autocontenido; release atomico (DECISION-0018).

## 4. Fuera de alcance

- El RELEASE v1.0 en si (bump de protocol_version a 1.0.0 + CHANGELOG + tag): es paso aparte con APROBACION
  HUMANA, despues de D2.4 + DECISION-0020 + fix prune. Fase B/7. Cambio incompatible => blocked.

## 5. SemVer: MINOR (documentacion aditiva).
