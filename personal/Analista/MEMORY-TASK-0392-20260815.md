## Las cinco lecciones, en orden de valor

1. **La mutacion decisiva es BORRAR el entregable, no romperlo.** Restaure la guia PRE-FIX
   (`546ce539~1`) -> exit 0. Borre la guia entera y revirti el README -> **exit 0 igual**. Una
   prueba que sobrevive a la ausencia de lo que valida no valida nada. Cuando el entregable es
   PROSA (una skill, una guia) y la prueba es CODIGO, el acoplamiento entre los dos es lo primero
   que hay que atacar: si la prueba no ABRE el fichero, no puede gatearlo.
2. **Un test que re-declara su propio criterio esta verde por construccion.** Aqui:
   `own = [... if MARKER in r]`, `visible = [... if MARKER not in r]` contra una constante del
   mismo fichero. `len(own)==2 and len(visible)==2` es la misma frase dicha dos veces sobre
   conjuntos complementarios. Regla: **buscar el `import`**. Si el filtro bajo revision no se
   importa de ningun sitio, la unica produccion bajo prueba es el test.
3. **Un fixture tiene que REPRODUCIR el fallo de campo, no ilustrarlo.** NOVA midio 7/7 propios con
   `Co-Authored-By: Claude (Opus|Fable|Sonnet)`. El fixture entregado usaba
   `Co-Authored-By: Shared Model <...>`, que el filtro viejo **no matchea**: control historico
   0/4, no 4/4. Levante los mismos cuatro commits con el trailer con forma de NOVA y ahi si
   discrimina (viejo 4/4, nuevo 2/2). **El numero del informe de campo es el objetivo a reproducir**;
   si tu fixture no lo alcanza, no estas montando el escenario que fallo.
4. **Una asercion anclada a una POSICION no mide el fenomeno.** El "mailbox alert" era
   `MSG-... in git show --name-only HEAD~2`. Dos mutaciones lo mataron: mover la MISMA entrega del
   commit 2 al 4 -> dice False con la entrega presente; poner un fichero plano con ese nombre en la
   raiz, sin directorio de mailbox -> dice True. **Mover el fenomeno de sitio y ponerlo donde no
   debe**: las dos direcciones, siempre.
5. **Un secreto que viaja en el cuerpo del commit se publica al usarlo.** La marca de coordinador
   es un trailer; la recupere con un `git log` (`coord-session-proof-7f6d`) y silencie dos commits

   Pero **decir el atenuante importa**: el paso 7 de la guia declara que la alerta de mailbox no la
   cancela el filtro, asi que la entrega que ABRE mensaje sigue sonando. El agujero real es la
